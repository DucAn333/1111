# PlaywrightNguyenDucAn

## Environment setup

Copy `.env.example` to `.env` and replace the placeholder values with your private test URL and credentials:

```env
LINK_URL=your_orangehrm_url
ORANGEHRM_USERNAME=your_username
ORANGEHRM_PASSWORD=your_password
ORANGEHRM_USERNAME1=your_username1
ORANGEHRM_PASSWORD1=your_password1
```

The `.env` file is ignored by Git and must not be committed. Keep the real URL and credentials only in your local `.env` file.
